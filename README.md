# SPsolucionesBGA

Clon de SPBogota para el punto de venta Soluciones BGA.

Apunta al proyecto Supabase **sp_SolucionesBGA** (`ngjpndqmkhhdqjjljfmp`).

## Setup

```bash
cd spappweb
npm install
npm run dev
```

Node 20+. La app corre en http://localhost:3000.

## Estructura

- `spappweb/` — panel admin Next.js
- `supabase/` — migraciones SQL (referencia; el schema ya está aplicado en Supabase)
